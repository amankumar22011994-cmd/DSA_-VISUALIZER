// SECTION 02
unordered_set HashSet
Sirf unique values — no duplicates, no order, blazing fast
💡
Kab use karein? Jab sirf check karna ho ki element exist karta hai ya nahi. Duplicates automatically ignore ho jaate hain.
Create / Initialize
#include <unordered_set>
using namespace std;

// Method 1: Empty set
unordered_set<int> st;

// Method 2: Initializer list se directly
unordered_set<int> st = {10, 20, 30, 40};

// Method 3: Vector se (duplicates automatically hatenge!)
vector<int> v = {1, 2, 2, 3, 3, 3};
unordered_set<int> st(v.begin(), v.end()); // {1, 2, 3}

// Method 4: String set
unordered_set<string> words = {"hello", "world"};
Insert
// insert() — standard way
st.insert(10);
st.insert(20);

// emplace() — faster! (C++11)
st.emplace(30);

// Duplicate? Ignore!
st.insert(10); // silently ignored
Delete
// Value se erase
st.erase(20);

// Sab hatao
st.clear();

// Iterator se erase
auto it = st.find(30);
if(it != st.end())
    st.erase(it);
Search / Find — 3 Tarike
// Method 1: find() — iterator return karta hai
if(st.find(20) != st.end())
    cout << "Found!\n";

// Method 2: count() ★ SHORTCUT ★ — 0 ya 1
if(st.count(20))
    cout << "Present!\n";

// Method 3: contains() — C++20 (sabse clean)
if(st.contains(20))
    cout << "Yes!\n";
⭐
Pro tip: Competitive programming mein st.count(x) sabse fast likhne ka tarika hai. Sirf ek function call — 0 ya 1 return.
Iterate + Size + Empty
// Range-based loop (recommended)
for(auto x : st)
    cout << x << " ";

// Size aur empty check
cout << st.size();    // kitne elements hain
if(st.empty())      // khaali hai?
    cout << "Empty set\n";
Complete Example
#include <iostream>
#include <unordered_set>
using namespace std;

int main() {
    unordered_set<int> st = {10, 20, 30};

    st.insert(40);
    st.insert(10);   // duplicate → ignored

    if(st.count(20))
        cout << "20 present hai\n";

    st.erase(20);

    for(auto x : st)
        cout << x << " ";
    // Output: 40 30 10 (order fixed nahi hoga!)
    return 0;
}
// SECTION 03
unordered_map HashMap
Key → Value pairs store karo — dictionary ki tarah
💡
Kab use karein? Jab kisi key ko ek value se map karna ho. Roll → Name, Word → Frequency, City → Population.
Create / Initialize
#include <unordered_map>

// Method 1: Empty map
unordered_map<int, string> mp;

// Method 2: Initializer list
unordered_map<string, int> marks = {
    {"Aman", 95},
    {"Rahul", 88},
    {"Priya", 92}
};

// Method 3: auto keyword (modern C++)
auto mp2 = unordered_map<int, int>{};

// Method 4: Reserve karo (performance ke liye)
unordered_map<int, int> mp3;
mp3.reserve(1000); // 1000 elements expected
Insert — 4 Tarike
unordered_map<string, int> mp;

// Method 1: [] operator — sabse aasaan
mp["Aman"] = 95;   // insert ya overwrite dono

// Method 2: insert() — sirf nai key ke liye
mp.insert({"Rahul", 88});
mp.insert(make_pair("Priya", 92));

// Method 3: emplace() ★ Fastest ★
mp.emplace("Rohan", 76); // in-place construct

// Method 4: insert_or_assign() — C++17
mp.insert_or_assign("Aman", 99); // guaranteed overwrite
Access — Bahut Zaroori ⚠️
// Method 1: [] — DANGEROUS agar key nahi hai!
cout << mp["Aman"];   // OK
cout << mp["XYZ"];    // ⚠ "XYZ" → 0 insert ho jayega!

// Method 2: at() — Safe, exception throw karta hai
cout << mp.at("Aman");  // OK
// mp.at("XYZ") → throws std::out_of_range

// Method 3: find() ★ BEST PRACTICE ★
auto it = mp.find("Aman");
if(it != mp.end()) {
    cout << it->first << ": " << it->second;
}

// Method 4: count() — exist karta hai?
if(mp.count("Aman")) cout << "Found!\n";
⚠️
Critical: mp["key"] sirf access hi nahi karta — agar key exist nahi karti toh woh default value ke saath insert bhi kar deta hai! (int ke liye 0, string ke liye "")
Iterate — 3 Modern Ways
// Method 1: Structured Binding ★ C++17 ★ (BEST)
for(auto& [key, val] : mp) {
    cout << key << " → " << val << "\n";
}

// Method 2: pair se (C++11)
for(auto& p : mp) {
    cout << p.first << " → " << p.second << "\n";
}

// Method 3: Iterator (old style)
for(auto it = mp.begin(); it != mp.end(); ++it) {
    cout << it->first << " → " << it->second << "\n";
}
Delete + Size + Clear
// Key se delete
mp.erase("Aman");

// Iterator se delete (find + erase)
auto it = mp.find("Rahul");
if(it != mp.end()) mp.erase(it);

// Size, empty, clear
cout << mp.size();   // element count
mp.empty();          // khaali hai?
mp.clear();          // sab delete
Complete Example
#include <iostream>
#include <unordered_map>
using namespace std;

int main() {
    unordered_map<string, int> marks = {
        {"Aman", 95}, {"Rahul", 88}
    };
    marks["Priya"] = 92;

    for(auto& [name, m] : marks)
        cout << name << ": " << m << "\n";

    marks.erase("Rahul");
    cout << "Size: " << marks.size(); // 2
    return 0;
}

map vs unordered_map
Kab kya choose karna chahiye?
Feature unordered_map map unordered_set set
Key-Value store ✓✓ ✗✗
Sorted order ✗ Random✓ Sorted ✗ Random✓ Sorted
Insert O(1) avgO(log n) O(1) avgO(log n)
Search O(1) avgO(log n) O(1) avgO(log n)
Worst Case O(n)O(log n) O(n)O(log n)
Memory Zyada Kam Zyada Kam
Internal Hash table Red-Black BST Hash table Red-Black BST
🚀
unordered_ use karo jab:
Fast lookup chahiye, order matter nahi karta, frequency count, DSA problems, competitive programming.
🌳
ordered use karo jab:
Sorted output chahiye, range queries lagani hain (lower_bound), min/max quickly chahiye.
Output Difference — Example

// unordered_map:       3 1 4 2   ← random order
